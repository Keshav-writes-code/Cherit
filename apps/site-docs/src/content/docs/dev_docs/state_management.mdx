so generally, an app's states fall into 2 main categories

<CardGrid>
  <Card title="Sessions States" icon="seti:clock">
    the non persistent states only required for current session and don't need to be persisted
  </Card>
  <Card title="Persistent States" icon="substack">
    the states that need to be persisted amoung sessions
  </Card>
</CardGrid>

In case of <span style="font-family: var(--font-astro-recoleta)" >Cherit</span>, we can divide states into further categories 

```mermaid
graph LR
    %% Root
    State["App States"]
    State@{ icon: "iconoir:code-brackets-square" }

    %% Level 1 - Split
    Persistent["Persistent State<br/>(Rust Managed / Disk)"]
    Persistent@{ icon: "iconoir:hard-drive" }

    Session["Session State<br/>(Svelte Memory)"]
    Session@{ icon: "iconoir:flash" }

    State --> Persistent
    State --> Session

    %% Level 2 - Persistent Sub-types
    Secure["Secure<br/>(OS Keychain via `keyring`)"]
    Secure@{ icon: "iconoir:lock-key" }

    Local["Local Config<br/>(Device Specific)"]
    Local@{ icon: "iconoir:pc-check" }

    Synced["Synced Config<br/>(Portable / Shareable)"]
    Synced@{ icon: "iconoir:cloud-sync" }

    Persistent --> Secure
    Persistent --> Local
    Persistent --> Synced

    %% Level 3 - Persistent Items
    LmmApi["LLM API Keys"]
    Secure --> LmmApi

    LocalFile["local_settings.json<br/>- Local LLM Path<br/>- Window Bounds"]
    Local --> LocalFile

    Workspaces["workspaces.json<br/>- Workspace paths mapping"]
    Local --> Workspaces

    SyncedFile["synced_settings.json<br/>- Theme & Fonts<br/>- Default LLM Provider"]
    Synced --> SyncedFile

    %% Level 2 - Session Items
    SingleComponent["Component States<br/>(Active Drafts)"]
    MultiComponent["Multi Component<br/>(Context Menu)"]
    Global["Global States<br/>(Memory File Tree)"]

    Session --> SingleComponent
    Session --> MultiComponent
    Session --> Global
```

## Secure States
although these states come under Persistent States, they are not stored in a `.json` file, instead it will be stored in the OS-native Keychain using either the [Stronghold](https://v2.tauri.app/plugin/stronghold/) or [Keyring](https://crates.io/crates/keyring) Plugin (not decided on which to use yet)
