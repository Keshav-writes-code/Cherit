To sync Markdown notes between devices, you can use any file syncing solution you like (Nextcloud, Dropbox, Google Drive, etc.).

in the future, Cherit will provide a baked in solution and no manual setup will be required like this one

for now, for the best privacy and performance, we recommend **Syncthing**. It's open-source, free, and syncs directly between your devices without storing data in the cloud.

2. ### Run on Startup

    on Desktop, we need to setup syncthing to auto-start when system boots

    <Tabs syncKey="os">
      <TabItem label="Windows" >

        `View > Settings > SyncTrazor > Start on Login`\

      </TabItem>
      <TabItem label="Macos" >

      </TabItem>

3. ### Configure

    both device need to be one the same local network.\
    a hotspot connection from mobile device to desktop devices also works

    #### Pairing
    1. open the syncthing app on your desktop, go to\
      `Top Right Corner > Actions > Show ID`
    2. open your mobile Syncthing app
    3. go to **Devices** tab, click  `top right button > add a device`
    4. for the **ID** column, click the QR code icon button next to it
    5. Scan the QR code, shown on desktop screen
    6. in the `Name` field , Set a name for your desktop device, e.g. `PC`
    6. Click the Tick button on top right
    7. now on your desktop, you should see popup on the top asking you to **Add Device**
    8. CLick `Add Device` button
    9. in the next Popup, set `Device Name` field to any name, e.g. `Mobile`
    
    
    #### Syncing
    1. Open the Syncthing app on mobile, go to\
      `Folder Tab > Top Right Corner > Add folder Button`
    2. Set `Folder Label` to `Cherit notes`
    3. set `Directory` field to the same folder that you choose for your Cherit's vault
    4. just below that, turn on the Switch next to `PC`. making your desktop share this folder with the mobile
    5. now on your desktop, you should see popup on the top asking you to accept the Invitation sent from the mobile for sharing the folder.
    6. CLick `Accept` button and in the following popup, in the `Directory` specify the location of your notes on your desktop
